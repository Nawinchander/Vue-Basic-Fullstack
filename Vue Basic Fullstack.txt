Vue Full Stack Project (Vue + Node.js + Express + MongoDB + SQL)

This is a basic full stack project using:

Frontend: Vue 3, Axios, Props, Event Handling, Two-way Binding
Backend: Node.js, Express.js, REST APIs
Databases: MongoDB + MySQL

Express API Routes

MVC Folder Structure

Step-by-Step Flow
User enters name/email in Vue form
Vue sends POST request via Axios
Express API receives request
Data stored in MongoDB + MySQL
Vue fetches updated users list
UserList receives data via props
